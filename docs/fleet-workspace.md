# 舰队管理使用指南

舰队主机提供一个网页，集中管理多台子服务器。子服务器运行代理与节点进程；入站、用户、出口和路由都在主机网页配置。

## 接入第一台子服务器

1. 登录主机后进入“舰队管理”，点击“添加子服务器”。
2. 填写容易辨认的名称，例如“香港入口”；公网地址填写**子服务器的 IP 或域名**，用于生成客户端连接地址。
3. 点击“创建并获取接入命令”。卡片立即出现，状态为“待接入”。
4. 在弹窗确认**主机公网地址**，填写子服务器能够访问的 HTTPS 源站地址。这里不附加管理员面板路径；反向代理需转发 `/fleet/v1/`。
5. 复制接入命令到子服务器终端执行，再复制一次性令牌粘贴进去，按 Ctrl+D 结束输入，然后重启节点服务。
6. 回到主机等待状态刷新，通常不超过 15 秒。在线后点击“管理节点”，即可打开对应节点的入站与用户界面。

接入弹窗中的命令适用于使用 `scripts/install-fleet.sh node` 安装的 Linux 节点，默认程序位于 `/usr/local/unifiedproxy-node/node`、数据位于 `/usr/local/unifiedproxy-node/data`。**创建卡片不会代替你安装程序、配置 Mihomo 或登录 SSH。** 自定义安装目录或使用 Docker 时，请按实际路径执行同样的 `agent join` 参数，再重启相应节点进程。安装和手动接入示例见[运行与迁移指南](unifiedproxy-migration.md#接入)。

令牌有效期 15 分钟，仅用一次；命令通过标准输入接收令牌，不将其放入命令行。过期或接入失败时，打开卡片的“获取接入命令”；需要重绑身份时，在“更多操作”选择“重新生成接入信息”。

## 看懂卡片与操作范围

| 显示或入口 | 含义 |
|---|---|
| 待接入 | 已登记卡片，还没有收到子服务器连接 |
| 在线 | 最近收到了节点上报；仍需结合代理内核和配置状态判断是否可用 |
| 离线 | 以前连接过，当前没有及时上报；不代表已运行的代理一定停止 |
| 已吊销 | 主机已撤销该节点接入权限；已有代理进程可能继续运行 |
| 配置已同步 | 节点上报的配置版本与主机期望版本一致 |
| 等待同步 | 主机已发布新版本，等待节点领取、校验和应用 |
| 管理节点 | 切换当前编辑对象并打开该节点的入站列表 |
| 更多操作 → 出口与路由 | 打开该节点的出口编辑页，可继续切换路由规则 |
| 顶部节点选择器 | 显示当前编辑对象；修改前先确认选择的服务器名称 |
| 主机全局默认配置 | 编辑供节点套用的默认设置，不在主机运行代理内核 |

卡片同时显示代理内核状态、节点版本、流量与最近连接时间。搜索支持名称、地址和节点 ID；点击统计卡或状态筛选可缩小列表。名称与地址必须点击“保存信息”才会保存，取消或按 Escape 会放弃本次修改。

## 按任务寻找功能

| 想做什么 | 操作入口 |
|---|---|
| 添加入站、生成节点、管理用户 | 服务器卡片 → 管理节点 |
| 配置出站、出口策略与分流 | 更多操作 → 出口与路由 |
| 再次下发已有配置 | 更多操作 → 发布当前配置 |
| 批量巡检、更新 Geo、更新内核或 Agent | 勾选服务器 → 批量操作 → 选择操作 |
| 修改多台服务器的用户配额或套用主机默认 | 勾选服务器 → 批量操作 → 修改用户配额 / 应用全局默认 |
| 查看任务进度与失败原因 | 任务记录 → 最近任务 → 展开一条记录 |
| 获取用户的聚合订阅 | 用户订阅 → 读取用户订阅 → 复制订阅地址 |
| 完整备份、历史 merit.json 导入、恢复或 WebDAV | 备份与迁移 |
| 查看主机公钥、管理中央证书、更新控制端 | 主机维护 |
| 编辑完整模型、辅助服务 JSON 或创建 Sidecar | 高级配置 → 选择服务器 → 展开相应项目 |
| 撤销节点权限 | 更多操作 → 吊销接入权限 → 确认 |

普通状态采集无需参数。检测出口需要子服务器实际可用的 SOCKS5 地址；更新 Agent 需要 HTTPS 更新包和 SHA256。尚未接入或未声明相应能力的节点会显示说明，避免提交无法执行的任务。修改配额、套用配置、更新、恢复和吊销等操作需要在界面再次确认。

原始 JSON 编辑仍保留在高级折叠区，日常使用无需打开。15 秒状态轮询会更新卡片与任务结果，并保留正在填写的任务表单。

## 界面回归验收

仅在 orca-linux 容器的 `/workspace` 内运行：

```sh
go build -o dist/control ./cmd/control
python3 scripts/acceptance/browser-smoke.py --binary dist/control
go test ./...
go vet ./...
```

浏览器验收启动独立临时主机，使用真实登录、节点登记、令牌签发、模型发布、配额和备份接口；在线心跳显示使用明确的模拟数据，不代表已连接真实公网子服务器。覆盖十一种现有语言的页面加载、五套配色的十种明暗组合、390px 手机布局、表单草稿保留、订阅范围和文字对比度。截图与结果写入 `dist/fleet-browser/`。
