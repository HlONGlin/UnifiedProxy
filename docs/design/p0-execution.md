## 不变约束

- 页面、功能入口、接口、现有备份与数据目录兼容保留。视觉改造不删交互。
- 新增要求：最老版本至当前 UnifiedProxy 的备份能导入，NaïveProxy 除外；实际保存、重启、再备份验证，而非只检查 JSON 能解析。
- 管理员、节点认证身份和任务的迁移须区分业务数据与失效的运行状态；不得静默丢弃不能迁移的字段。
- 所有依赖安装、运行、预览、构建、测试仅通过 `C:/Users/honglin/.local/bin/orca-linux.ps1` 启动的 `orca-linux:local` 容器，在 `/workspace` 执行。
- Windows 只编辑文件和执行 Git；Git worktree 的宿主机路径不向容器伪装成可用路径。
- 每阶段独立提交；失败修复后才进入下一阶段。
